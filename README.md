# Проект "Интернет магазин - Ансат"

## Описание:

Проект "Интернет магазин - Ансат" - это проект, нацеленный на отработку и закрепление основных тематик ООП:
* Работа с классами
* Работа с разными режимами доступа к атрибутам и методами
* Использование магических методов
* Применение наследования и множественного наследования
* Работа с исключениями и описание своих.

## Для работы потребуется виртуальное окружение Poetry и Python 3.13.2

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/kpac955/OOP_home_1.git

```

2. Установите фреймворк "pytest" для выполнения тестов каталога "tests" 
```
poetry add --group dev pytest
```

 ## В каталоге SRC 
 на данный момент содержатся файлы "product.py" и "category.py", в которых реализованы:

* атрибуты с описанием типов значений, которые будут в них храниться.
* метод инициализации "__init__(self)"
* в файле product.py созданы классы наследники Smartphone и LawnGrass от родителького класса Product с добавленными для них свойствами.
* в файле product.py доработана функциональность сложения __add__ , что бы можно было складывать товары только из одинаковых классовых продуктов путем использования функции type() и isinstance()
* в файле category.py в функцию add_product добавлена проверка на принадлежность объектов определенному классу с помощью функции isinstance()

## В каталоге tests 
на данный момент содержатся файлы "test_product.py" и "test_category.py" c обновленными реализованными в них тестами модулей "product.py" и "category.py"
